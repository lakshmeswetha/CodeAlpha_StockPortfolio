# CodeAlpha_StockPortfolio

  A command-line program that enables users to track and evaluate their stock portfolio using pre-defined market prices.
  Users can input their stock holdings interactively, view formatted investment breakdown and export the result as either a .txt or .csv file for record keeping. Users can also choose not to export the stock records.
  This is built as a part of CodeAlpha Summer Internship Program in Python Programming.
